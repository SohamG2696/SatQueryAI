# SatQuery AI — Region Grounding Module

## Status: READY 🏆

Integrates spatial region localization from a single satellite image + natural-language query.

## Capabilities
- Detects target bounding boxes matching descriptive spatial features (e.g., "locate the smallest forest region", "highlight water body").
- Returns normalized bounding-box coordinates `[x1, y1, x2, y2]`.
