# SatQuery AI — Bi-Temporal Change-VQA Module

## Status: READY 🏆

Integrates bi-temporal change detection and reasoning from pairs of temporal images (T1 Before, T2 After) + natural-language query.

## Capabilities
- Compares multi-temporal land cover / urban / environmental changes.
- Evaluates queries such as: "Did vegetation increase between 2022 and 2025?".
